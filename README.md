# Filmoteka Team Project

Filmoteka is a movie discovery web application built with Parcel, vanilla JavaScript, Handlebars templates, and Sass.

The app allows users to browse movies, search by title, view movie details, watch trailers, and manage personal movie lists in local storage.

## Main Features

- Browse popular movies on the Home page
- Filter movie lists by categories:
  - Popular
  - Top Rated
  - Upcoming
- Search movies by title
- Open movie details in a modal window
- Watch movie trailers in a trailer modal
- Add movies to personal lists:
  - Watched
  - Queue
- View and switch between Watched and Queue on My Library page
- Pagination for movie results
- Theme switching support
- Notification messages with Notiflix

## Pages

- Home: movie feed, filters, search, pagination
- My Library: personal Watched and Queue lists

## Tech Stack

- JavaScript (ES modules)
- Parcel 2
- Sass (SCSS)
- Handlebars
- Axios
- Notiflix
- basicLightbox / SimpleLightbox
- Swiper

## API

This project uses The Movie Database (TMDB) API.

Current API configuration is stored in src/constants/apiService.js:

- BASE_URL: https://api.themoviedb.org/3
- API_KEY: configured directly in source

Note:
For production-grade usage, keep API keys in environment variables and do not commit secrets to the repository.

## Project Structure

- src/index.html: Home page entry
- src/library.html: My Library page entry
- src/index.js: application bootstrap
- src/api: API request modules
- src/js: app logic (rendering, modals, pagination, local storage, filters)
- src/partials: reusable HTML partials
- src/template: Handlebars templates
- src/sass: styles

## Prerequisites

- Node.js 16+ (Node.js 18+ recommended)
- npm

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

## Run Locally

Start development server:

```bash
npm start
```

Parcel will run the app at:

- http://localhost:1234

## Build for Production

```bash
npm run build
```

Build output is generated by Parcel in the dist directory.

## Deploy

The project is configured with a public URL for GitHub Pages in package.json:

## NPM Scripts

- npm start: run Parcel dev server for all HTML entry points in src
- npm run build: create production build for all HTML entry points in src

## Troubleshooting

If you see a Browserslist warning (caniuse-lite is outdated), run:

```bash
npx browserslist@latest --update-db
```

Then restart the dev server.
